# A4 二十四院罗盘（建议）

**做完的样子**：点左下角的罗盘，画面压暗，罗盘从左下角长到屏幕中间，变成一面直径约 840 像素的盘：外圈是二十四山的字和刻度，往里一圈是 24 个学院的鎏金院徽，再往里是学院的简称，盘心写「二十四院」。指着一个院徽，它还原本色、外圈变红，一根红线从它落到沙盘上它的楼，旁边一块小牌写学院名和楼名。点它，罗盘收起，镜头飞到那栋楼。转动沙盘时，罗盘跟着转（院徽和字保持正立）。对照 `alive-dial.jpg`。

**原理**：盘面是一张 SVG（`ui/dial.svg`），只有刻度和字。院徽由页面按 `emblems.json` 的 `dial.deg` 放在半径 `emblemRadius` 的圆上。整面盘和镜头的方位角反着转，所以「子」始终指着沙盘的正北，每个院徽大体指着它学院所在的方向（`ALIVE.md` 第 2 节）。

**只许改**：`src/stores/stage.ts`、`src/views/StageView.vue`、`src/components/stage/StageHud.vue`（罗盘改成可点）、`src/components/stage/StageCanvas.vue`（只为调试钩子加 `dial`）、`src/styles/stage.css`；新建 `src/components/stage/CollegeDial.vue`、`tests/e2e/stage-dial.spec.ts`；`tests/unit/stage-store.test.ts` 里追加。

## 要做的事

1. **入口**：W2 的罗盘（`stage-compass`）外面包一个 `button`，`aria-label="二十四院罗盘"`，点了 `openDial()`。`mode === 'tour'` 时不响应。`emblems` 为 `null` 时不响应。
2. **store**：`dialOpen`、`dialHover` 两个字段；`openDial()`、`closeDial()`（同时把 `dialHover` 清掉）、`hoverDial(no | null)`。`goHome()`、`pickCampus()`、`switchPack()`、`setTour(true)` 都先 `closeDial()`。
3. **`CollegeDial.vue`**（`dialOpen` 时渲染，`data-testid="stage-dial"`）：
   - **遮罩**：铺满视口，底色 `rgba(5, 8, 13, .62)`。点遮罩上盘面以外的地方 `closeDial()`。
   - **大小和位置**：`D = min(0.82 × 视口高, 840, 0.9 × 视口宽)`，盘心在视口中心。缩放 `k = D / emblems.dial.viewBox`。
   - **盘面**：`<img src="/campus3d/ui/dial.svg">`，`D × D`，`transform: rotate(−方位角deg)`，方位角每帧从 `getAzimuth()` 取（和 W2 的罗盘同一个值）。
   - **院徽**：每个学院一个 `button`（`data-testid="stage-dial-slot-<no>"`，`aria-label` 是学院全名）。角度 `θ = dial.deg − 方位角`（度），中心在 `盘心 + (R·sin θ, −R·cos θ)`，`R = emblemRadius × k`。按钮直径 `emblemSize × k`，圆形，底色 `rgba(7, 10, 15, .9)`，`box-shadow: 0 0 0 1px var(--st-gold3)`，里面 `EmblemMark`（`emblemSize × k − 6`，`gilt`）。**按钮本身不旋转**。
   - **不在当前沙盘上的**（它的 `buildingIds` 里没有一个在 `meta.buildings` 里）：按钮外面加一圈 1px 的金色虚线（`outline: 1px dashed var(--st-gold2); outline-offset: 3px`）。
   - **简称**：每个学院一个，中心在半径 `262 × k` 的同一个角度上，宋体 600 13px，月白 66%，正立。不在当前沙盘上的，下面一行 10px 小字：楼在别的沙盘上的写那块沙盘 `name` 去掉「校区」（例如「将军山」）；没有楼的写「待定」。
   - **盘心**：三行，居中：宋体 900 40px 鎏金色「二十四院」（字距 0.32em）；12px「石河子大学 · 六个校区」；11px 月白 38%「点院徽，去它的楼」。下面一个文字钮「收起」（`stage-dial-close`），点了 `closeDial()`。
   - **Esc** 键 `closeDial()`。
4. **指着一个院徽**（`pointerenter` 或键盘聚焦）：`hoverDial(no)`。这个按钮的 `EmblemMark` 换成 `color`，`box-shadow` 换成 `0 0 0 2px var(--st-red), 0 0 26px rgba(226, 0, 26, .6)`，简称变白。
   - 它的楼在当前沙盘上时，在最上层（盖过遮罩）画一根红线（`stage-dial-thread`）：二次曲线，起点是按钮中心往楼的方向走 6% 的点，终点是 `project(楼的 anchor)`，控制点是两点的中点再往上「两点距离 × 0.12」；描边 `--st-red` 1.8px；终点两个圆（半径 6 的空心、半径 1.8 的实心，朱红）。终点右边 14 像素一块小牌（左边 3px 朱红边，近黑底）：宋体 700 15px 学院名（去括号），下面 11.5px「<片区名> · <楼名>」。
   - 每帧重算（盘在转，楼的屏幕位置也在变）。
5. **点一个院徽**：
   - 楼在当前沙盘上：`closeDial()`，`showCollege(no)`。
   - 楼在别的沙盘上（`places.packOf[第一栋楼]` 有值）：`closeDial()`，`switchPack(那块沙盘)`，等新场景 `ready` 后 `showCollege(no)`。
   - 没有楼：不关，按钮旁边显示「位置待确认」1.5 秒。
6. **展开和收起的动画**：展开时整块盘从罗盘的位置（`transform-origin` 设成罗盘中心相对盘的位置）由 0.1 倍放大到 1 倍、透明到不透明，420 毫秒，`cubic-bezier(.2, .8, .2, 1)`；24 个院徽按 `dial.slot` 从小到大依次从 0.6 倍弹到 1 倍，相邻隔 18 毫秒。收起 260 毫秒，反过来。展开期间左下角的小罗盘隐藏。「减少动态效果」打开时全部立即完成。
7. **层级**：遮罩和盘在回答面板之上、顶栏之下。
8. **调试钩子**：`window.__campus3d.dial` 是 `dialOpen`。

## 常见错误

- 院徽跟着盘面一起转倒了：盘面 `img` 转，按钮不转，按钮的位置按角度算。
- 罗盘转反了：和 W2 一样，转的是 `−方位角`。
- 红线终点用了楼的题签点：终点是楼的 `anchor` 本身。
- 打开罗盘后滚轮还在缩放沙盘：遮罩要拦住 `wheel` 和拖动（`pointer-events: auto`）。
