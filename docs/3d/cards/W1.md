# W1 资产包 v3、整屏画布

**做完的样子**：打开 `/stage?3d=1`，整个窗口是全校的夜景沙盘：先是海报，3D 淡入，楼从中区向外长出来，镜头落到首页机位。没有任何界面，这是对的。对照 `docs/3d/reference/stage/all/stop-home.jpg`。

**前提**：`frontend/public/campus3d/packs.json` 存在且 `"version": "v3"`，七个沙盘的目录（`all/`、`by/`、`bq/`、`zq/`、`nq/`、`dq/`、`jjs/`）和 `ui/` 都在。不是的话停下，等协助方的文件。这张卡只用到 `all`；别的沙盘 W3 才会换过去，但这张卡的单元测试要把七个都查一遍。

**只许改**：新建 `src/stage/packs.ts`、`src/views/StageView.vue`、`src/components/stage/StageCanvas.vue`、`src/styles/stage.css`；改 `src/campus3d/meta.ts`、`src/campus3d/scene.ts`、`src/router/index.ts`、`src/App.vue`；新建 `tests/unit/packs.test.ts`、`tests/unit/glb-v3.test.ts`、`tests/e2e/stage.spec.ts`。

## 要做的事

1. **`packs.ts`**：
   - 按 `STAGE.md` 第 5.2、5.5 节写类型 `PackIndex`、`Places`。
   - `parsePackIndex(json)`：校验 `version === 'v3'`；`default` 是某个包的 `id`；每个校区的 `pack` 都是某个包的 `id`；每个包的 `name`、`meta`、`glb`、`posterDesktop`、`posterMobile` 是非空字符串，`zones` 是非空的字符串数组，`buildings` 是正整数。不合格抛 `Error`，信息里写明字段名。
   - `packUrl(path)`：返回 `'/campus3d/' + path`。
   - `loadPackIndex()`、`loadPackMeta(index, id)`、`loadPlaces()`：用 `fetch` 取文件。**后端对找不到的文件返回 200 加首页 HTML**，所以要先看响应头 `content-type` 含 `json`，不含就抛 `Error`（信息里带上地址）。`loadPackMeta` 取回后交给现有的 `parseMeta`。
2. **`meta.ts`**：给 `CampusMeta` 加上 `STAGE.md` 第 5.3 节的字段，**都是可选的**（v2 的元数据没有它们）。`parseMeta` 里：只有 `meta.pack` 存在时才做下面的校验，不存在时行为和现在完全一样。
   - `zones` 是非空数组；带 `node` 的片区必须有 `label`（3 个有限数）。
   - `shells` 里每个楼号都在 `buildings` 里。
   - `buildings` 的每个键在 `focus` 里都有一项，`position` 和 `target` 各是 3 个有限数。
   - `stops.home` 存在。
   - `look.zone.nodePrefix`、`look.pin.node` 是非空字符串；`look.star.home` 是 3 个有限数；`look.star.lift`、`look.sign.lift`、`look.tour.degPerSec`、`look.hud.scaleMeters` 是大于 0 的有限数。
3. **`scene.ts`**：
   - `createCampusScene` 的 `opts` 增加 `homeStop?: string`，不传时是 `'overview'`。开场动画结束时镜头去的、以及不播开场动画时一开始所在的停靠点，都改用它。
   - `goTo` 的第一个参数除了停靠点名字，也接受 `{ position, target }` 对象。传对象时，调试钩子的 `stop` 记为 `'focus'`（W5 会改成带楼号的写法）。
   - 加载后，除了原来收集的 `H_` 组，再收集两样（**都只收父节点是模型根节点的，都不要改它们的缩放**）：名字以 `meta.look.zone.nodePrefix` 开头的组；名字等于 `meta.look.pin.node` 的组。元数据里没有 `look.zone`、`look.pin`（v2）时跳过，不抛错。
   - 调试钩子新增 `pack`（`meta.pack?.id ?? ''`）、`shellNodes`（`H_` 组的个数，就是原来的 `hotNodes`，两个都留着）、`zoneNodes`。
4. **`StageCanvas.vue`**：一个 `position: fixed; inset: 0` 的容器（`data-testid="stage"`，class 里带 `stage`），里面是海报 `img`（`stage-poster`）和 `canvas`（`stage-canvas`），都铺满容器。海报 `object-fit: cover; object-position: 50% 50%`。它要做的事和 `CampusHero.vue` 相同，照那里的做法再写一遍（**不许改 `CampusHero.vue`**）：
   - 用现有的 `decideMode()` 判定；静态模式只显示海报。
   - 3D 模式：动态 `import()` `scene.ts`，用 `packs.json` 里 `default` 那个包的地址调用 `createCampusScene`，`homeStop` 传 `'home'`，`playIntro` 用现有的 `decideIntro()` 决定。
   - 加载中在容器顶边显示一条 2px 的朱红进度线；第一帧画完后海报用 400 毫秒淡出。
   - 加载失败：回到海报，调试钩子 `status` 为 `error`。
   - 持续渲染的条件沿用 N3 的四条，其中「画框在视口里」改成观察这个容器。
   - 窗口尺寸变化时更新渲染尺寸和相机宽高比。**相机的 `fov` 始终是 `meta.camera.fov`，不随窗口变。**
   - 窗口宽高比超过 `meta.pack.posterAspect` 时，海报和画布的宽度取 `高度 × posterAspect`，水平居中。
   - 组件卸载时 `dispose()`。
5. **`StageView.vue`**：只放一个 `StageCanvas`。**`router/index.ts`** 加一条路由 `{ path: '/stage', name: 'stage', component: () => import('@/views/StageView.vue'), meta: { index: '—', title: '校园', stage: true } }`，放在通配路由之前。
6. **`App.vue`**：给 `<header class="topbar">` 和 `<footer>` 各加 `v-if="!route.meta.stage"`。别的不动。
7. **`stage.css`**：现在只写第 3.1、3.2 节的变量（放在 `.stage` 下）、`.stage { background: var(--st-ink); color: var(--st-moon); }`，以及给测试截图用的一条：`.stage.is-shot > :not(canvas) { visibility: hidden; }`（以后各卡加的界面层都要是 `.stage` 的直接子元素，这一条才盖得住）。在 `StageView.vue` 里 `import`，不要在 `main.ts` 里全局引入。

## 常见错误

- 元数据取回来是一段 HTML：地址少了 `all/`，后端回了首页。看第 1 步的 `content-type` 检查。
- 把包的地址写死成 `'/campus3d/all/…'`。地址一律从 `packs.json` 里那个包的 `meta`、`glb`、`posterDesktop`、`posterMobile` 取，W3 换沙盘时才不用改这里。
- 把 v3 的字段写成必填，根目录 v2 的元数据解析失败，首页沙盘的旧测试大面积变红。
- 收 `Z_` 组时没限制「父节点是根节点」，把 `Z_BQ_ring` 也收了进去，`zoneNodes` 变成 14。
- 海报和 3D 的画面左右对不上：海报没用 `cover`，或者把相机的 `fov` 按窗口比例改了。
