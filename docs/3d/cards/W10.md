# W10 在回答里近看（可选）

**做完的样子**：在全校沙盘上问「学生证丢了去哪补办」，镜头飞到大学生活动中心，面板里「办理地点」那一行的右边多一个小钮「近看」。点它：换成中区自己的沙盘，开场动画播完，镜头落到同一栋楼上，楼是红的，窗户一格一格看得清。回答面板一直在，不用重新问。对照 `stage-answer.jpg`（点之前）和 `stage-answer-zq.jpg`（点之后）。

**前提**：W5 做完。这张卡不依赖 W7、W8、W9。

**原理**：全校沙盘上楼小，适合看「在哪个校区」；校区自己的沙盘上楼大，适合看「是哪一栋」。换沙盘之后再落到楼上，用的就是 W5 里「这栋楼在另一块沙盘上，点这里换过去」的同一套做法，这张卡只是多了一个入口。

**只许改**：`src/stores/stage.ts`、`src/components/stage/AnswerPanel.vue`、`src/views/StageView.vue`、`src/styles/stage.css`；`tests/unit/stage-store.test.ts` 里追加；新建 `tests/e2e/stage-near.spec.ts`。

## 要做的事

1. **`stores/stage.ts`** 加一个只读的计算值 `nearPack: string | null`，从上到下命中第一条：
   - `place` 是 `null`，或者 `meta` 是 `null`：`null`。
   - 当前包不是默认包：`null`（已经在近看的沙盘里了）。
   - 取这栋楼的片区号 `meta.buildings[place.buildingId].zone`。在 `packs.json` 的 `packs` 里找一个**不是默认包、`zones` 里有这个片区号**的包，找到就是它的 `id`，找不到就是 `null`。
   - 不要按楼号的前两个字母去猜，也不要查 `campuses`：第一附属医院（`FY`）和护士学校（`HX`）不是校区，但它们的楼在 `nq` 这块沙盘上，按 `zones` 找才找得到。
2. **`stores/stage.ts`** 加一个动作 `enterPlace()`：`nearPack` 是 `null` 时什么都不做。否则记下 `place.buildingId`，`switchPack(nearPack)`，等新沙盘的元数据和场景都准备好之后，再 `showAnswer(记下的楼号)`。
   - 「等新沙盘准备好再落到楼上」这件事，W5 第 7 步给 `stage-other-pack` 已经做过一遍。**把那一段提出来，两个入口共用**，不要抄第二份。
   - 等的过程中用户又问了新的问题，或者又换了沙盘：记下的楼号作废，不再 `showAnswer`。
3. **`AnswerPanel.vue`**：`nearPack` 不为空时，在「办理地点」这一节（`stage-panel-place`）里、楼名的右边显示一个小钮（`stage-place-near`），写「近看」。样式同左侧校区列表里的「近看」，但是横排：宋体 600 12.5px，字距 0.34em，金色字，1px 金色边，内边距 3px 8px，直角。点它：`enterPlace()`。
4. 换沙盘期间回答面板**不关、不清空**：面板的内容来自 `chat` store 的最后一轮，和沙盘无关。「办理地点」这一节在 `place` 为空的那一小段时间里不显示，新沙盘准备好、`showAnswer` 之后重新出现。

## 常见错误

- 换完沙盘楼没有变红：`showAnswer` 调早了，新沙盘的元数据还没放进 store，被当成 `null` 处理掉了。要等 `setMeta` 和场景 `ready` 都发生之后。
- 换完沙盘镜头去了奇怪的地方：用了全校沙盘里那栋楼的近景机位。同一栋楼在两块沙盘里坐标不同，机位要从新沙盘的 `meta.focus` 里取。
- 附属医院的楼没有「近看」：按 `campuses` 找了。要按 `packs[].zones` 找，见第 1 步。
- 点了「近看」又重新问了一遍：把换沙盘做成了重新发送问题。面板内容来自 `chat` store，不需要重发。
