# W4 问话栏和回答面板

**做完的样子**：在 `/stage` 底部的问话栏里提问，右边滑出回答面板：标题「答」，正文，下面是一张张宣纸色的公文卡，每张盖着「已审定」的章。追问、资料不足、超出范围、向导、出错，各有各的面板。镜头这张卡里还不动。对照 `stage-answer.jpg` 的右半边和底部。

**只许改**：`src/views/StageView.vue`、`src/styles/stage.css`；新建 `src/components/stage/AskDock.vue`、`src/components/stage/AnswerPanel.vue`；新建 `tests/e2e/stage-ask.spec.ts`；`tests/e2e/fixtures/api.ts` 里**只许追加**新的假数据，不许改已有的。

**不许改** `src/stores/chat.ts` 和 `src/api/client.ts`。舞台直接用现有的 `useChatStore()`：`send(text)`、`pickChoice(id)`、`retry(requestId)`、`cancel()`、`restore()`、`newSession()`、`turns`、`busy`。

## 要做的事

1. **`AskDock.vue`**（`stage-dock`）：
   - 状态行（`stage-status`）：一个金色小菱形加文字「智多星在线 · 知识库 N 条审定证据」，N 来自现有的 `useKbMeta()`；还没取到时显示「正在连接知识服务…」。`store.busy` 时文字换成「正在翻查审定资料…」，后面跟一个「不等了」的文字钮，点了调 `store.cancel()`。
   - 输入框（`stage-input`）和「问」字钮（`stage-ask`）。回车或点钮：去掉首尾空白，不为空且 `store.busy` 为假时调 `store.send(text)`，清空输入框。**不要用 `useGo().ask()`，它会跳到 `/chat`。**
   - 示例问题：`store.turns` 为空时，在输入框上方显示四个：「学生证丢了去哪补办？」「国家励志奖学金要什么条件？」「宿舍水管坏了怎么报修？」「借教室要提前几天申请？」。点了直接发送。
   - 进入页面时调一次 `store.restore()`。
2. **`AnswerPanel.vue`**（`stage-panel`）：只显示**最后一轮**。取 `store.turns` 里最后一条 `role === 'assistant'` 的记录，以及它前面最近的一条用户消息。没有记录时不渲染。四个角的包金用四个空元素或伪元素做。
   - 用户的问话：面板上方一小条宣纸色的字（`stage-question`）。
   - `status === 'pending'`：标题「答」，正文「正在翻查审定资料…」。
   - `response.status === 'answer'`：标题「答」，右上「依据 N 条审定证据 · S 秒」。小标题「回答」，下面用现有的 `AnswerBlocks` 组件渲染 `answer.blocks`。小标题「官方出处」，下面每条出处一张公文卡（`stage-doc-1`、`stage-doc-2`…）：
     - 标题 `citation.title`；第二行 `issuer`，有 `locator` 时后面加「 · 」和它；有 `time_condition` 时再起一行写它。
     - 右侧 `<img>` 引 `/campus3d/ui/stamp.svg`，按第 5.6 节的尺寸和角度。
     - 点卡片：在卡片下方展开 `excerpt`（有的话）和一个「看原文」链接，链接到 `/sources/<encodeURIComponent(id)>`。再点收起。
     - `AnswerBlocks` 发出 `cite` 事件时，展开对应的那张卡并滚到它。
   - `clarify`：标题「还要问你一句」，正文是 `clarify.question`，下面每个选项一个钮，点了调 `store.pickChoice(id)`。没有选项时显示 `input_hint`。
   - `insufficient`：标题「资料不足」，正文 `message`；有 `unknown_fields` 时加一行「还缺：」用「；」连起来；有出处的照样列公文卡。
   - `out_of_scope`：标题「不在办事范围内」，正文 `message`。
   - `workflow`：标题「办事向导」，`workflow.name`、`workflow.summary`，`historical` 为真时加一个「历史演示」的小标签，一个「进入向导」的钮，去 `/workflows/<flow_id>`。
   - `status === 'error'`，或 `response.status` 是 `error` / `model_unavailable`：标题「这一轮没有答出来」，正文是错误信息，一个「再试一次」的钮调 `store.retry(request_id)`。
   - `status === 'cancelled'`：标题「答」，正文「这一轮已经取消。」
   - 面板最底一行小字：「回答依据官方审定资料生成；没有采集到的信息会写明不足。」右边一个「全部对话」的链接去 `/chat`，一个「重新开始」的文字钮调 `store.newSession()`。
3. **`AnswerBlocks` 的样式是给白底写的**（在 `swiss.css` 里：白色底、黑字、红色序号）。不许改 `swiss.css` 和 `AnswerBlocks.vue`，在 `stage.css` 里用 `.stage .blocks`、`.stage .block` 这样的选择器盖掉：外框去掉；每段背景透明，段与段之间一条 `rgba(232, 237, 243, 0.10)` 的细线；正文月白；左边的小标签（要点、办理、步骤、材料、提示）用宋体、鎏金色；`kind-note` 的段落背景也透明，字用 `--st-moon2`；引用角标用鎏金色；悬停时背景不变。**面板里不许出现红色的字。**
4. 面板出现时按第 4.4 节滑入。面板内容超高时内部滚动，滚动条用细的深色样式。
5. 这张卡里**不做**「办理地点」那一行、红色引线、镜头移动，那是 W5 的事。

## 常见错误

- 面板把整段对话历史都列了出来。舞台上只显示最后一轮，历史在「全部对话」里看。
- 回答正文里的换行丢了：`AnswerBlocks` 自己处理了，不要把 `text` 另外拼成一段。
- 公文卡的样式没有放在 `.stage` 之下，`/chat` 页面里的出处列表也变了样。
- 从向导页回到舞台后面板空了：进入页面时没有调 `store.restore()`。
