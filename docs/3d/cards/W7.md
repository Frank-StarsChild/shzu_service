# W7 智多星（可选）

**做完的样子**：校园上空悬着一颗带十字星芒的光点，旁边三个字「智多星」。提问后它开始一明一暗地闪；回答落到楼上时，它用不到一秒飞到那栋楼的上方，身后拖一道渐隐的弧线。对照 `stage-home.jpg` 和 `stage-answer.jpg`。

**原理**：星是页面上的一个 `div`，不是 3D 物体。它「跟随」一个场景坐标点：每帧用 `project()` 把这个点换成屏幕坐标，把 `div` 放过去。让它飞，就是让它跟随的点在两个场景点之间移动。

**只许改**：`src/views/StageView.vue`、`src/styles/stage.css`、`src/components/stage/SceneSigns.vue`（只为画拖尾）；新建 `src/components/stage/ZdxStar.vue`、`tests/e2e/stage-star.spec.ts`。

## 要做的事

1. **样子**（都用 CSS，不用图片）：
   - 核心：10×10 的白色圆点。
   - 光晕：`box-shadow: 0 0 0 2px rgba(255,255,255,.35), 0 0 18px 6px rgba(190,220,255,.85), 0 0 60px 22px rgba(120,170,255,.45)`。
   - 星芒：两个伪元素，一横一竖，各长 74px、粗 1.5px，中间白、两端透明的线性渐变（这是星自己的一部分，不算第 3.4 节限制的渐变）。
   - 字：星的右上方（偏移 `16px, −30px`），宋体 600 13px，字距 0.4em，白色，带一圈深色的字影保证看得清。
2. **跟随哪个点**（`ZdxStar.vue` 里算）：
   - `mode` 是 `home`、`campus`、`tour`：`meta.look.star.home`。
   - `mode` 是 `answer`：楼的 `anchor`，Y 再加 `meta.look.star.lift`。
3. **飞**：目标点变了的时候，用 900 毫秒从当前点移到新点（先慢后快再慢，和镜头的缓动一样）。途中的点：两端点线性插值，再在 Y 上加一个拱起 `sin(π·t) × 两点间距离 × 0.25`，所以轨迹是一道弧。每帧在 `onFrame` 回调里算位置、调 `project()`。`visible` 为假时隐藏。
4. **拖尾**：飞行途中，在连线层里画一条 `path`（`stage-star-trail`）：从起点的屏幕位置到星当前的屏幕位置的二次曲线，描边用一个从透明到白色的线性渐变（同上，属于星的一部分）。飞完后用 300 毫秒淡出再移除。
5. **状态**：`div`（`stage-star`）上带 `data-state`：
   - `idle`：平时。
   - `thinking`：`chat` store 的 `busy` 为真时。光晕按每 1.2 秒一次的 CSS 动画放大缩小（只改 `box-shadow` 的扩散半径和不透明度）。
   - `flying`：飞行途中。
6. 静态模式（没有 3D）下不显示星。开了「减少动态效果」：不闪动，位置直接跳过去，不画拖尾。

## 验证

`tests/e2e/stage-star.spec.ts`（1440×900，`/stage?3d=1&intro=0`）：
1. `ready` 后：`stage-star` 可见，`data-state="idle"`；它的中心和 `projectPoint(meta.look.star.home)` 相差不超过 3 像素。旁边有「智多星」三个字。
2. 把 `**/api/v1/chat` 的假数据改成延迟 1.5 秒再返回。问「学生证丢了去哪补办」：返回之前 `data-state="thinking"`。
3. 返回之后、`moving === false` 之前，至少有一次观察到 `data-state="flying"`，并且这时页面上有 `stage-star-trail`。
4. `moving === false` 再等 400 毫秒：`data-state="idle"`；星的中心和 `projectPoint([anchor[0], anchor[1] + meta.look.star.lift, anchor[2]])` 相差不超过 3 像素；`stage-star-trail` 已经不在。
5. 点 `stage-rail-ALL`，等 `moving === false` 再等 1 秒：星回到 `meta.look.star.home` 的投影位置。
6. 用 `/stage?3d=0` 打开：没有 `stage-star`。
7. 用 `page.emulateMedia({ reducedMotion: 'reduce' })` 重做第 2 到 4 步：始终没有出现过 `flying`，没有出现过 `stage-star-trail`，最后位置仍然正确。

截图存 `docs/3d/shots/W7-star.png`。

**反向验证**：把第 2 步里 `answer` 状态的 `+ meta.look.star.lift` 临时去掉，第 4 条必须变红；改回。

## 常见错误

- 星比镜头慢半拍或者抖：位置在 `requestAnimationFrame` 里另算了一遍。只在 `onFrame` 回调里算，和画面同一帧。
- 星挡住了面板上的字：星的层级要在面板之下。`z-index` 放在场景标签层（3），不要放在界面层。
- 镜头飞的时候星飞出了屏幕：正常。它跟随的是场景点，镜头到位后自然回到画面里。
