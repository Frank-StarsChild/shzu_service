# A1 院徽资产和 `EmblemMark`（必做）

**做完的样子**：页面上还看不出变化。有了一个读院徽清单的模块和一个画院徽的组件，后面几张卡都用它。打开 `/stage?3d=1&intro=0&emblems=1` 时，页面左上角临时排出 24 枚院徽（鎏金一排、本色一排），用来自查，对照 `docs/3d/reference/alive/emblems-contact.jpg`。

**原理**：院徽平时统一成鎏金，选中才还原本色（`ALIVE.md` 第 3.1 节）。鎏金不是一张金色的图，而是一个铺了金色渐变的圆，用院徽的蒙版（白色加透明）去「抠」出图形。这样 24 个院徽一个样式，颜色全由 CSS 控制。

**只许改**：`src/stores/stage.ts`、`src/views/StageView.vue`、`src/styles/stage.css`；新建 `src/stage/emblems.ts`、`src/components/stage/EmblemMark.vue`、`tests/unit/emblems.test.ts`、`tests/e2e/stage-emblems.spec.ts`。

## 要做的事

1. **`stage.css`**：`.stage` 下加变量 `--st-gilt`（值见 `ALIVE.md` 第 3.1 节）。
2. **`emblems.ts`**：
   - 类型 `College`（字段照 `ALIVE.md` 第 7.2 节，只写页面用到的：`no`、`name`、`short`、`zone`、`buildingIds`、`located`、`color`、`mask`、`kind`、`year`、`note`、`dial.slot`、`dial.mountain`、`dial.deg`）和 `Emblems`（`version`、`size`、`dial`、`colleges`）。
   - `loadEmblems(): Promise<Emblems>`：取 `/campus3d/emblems/emblems.json`，只取一次（缓存 Promise）。取到的内容 `colleges` 不是 24 条时抛错。
   - `emblemUrl(path: string): string`：`new URL('/campus3d/' + path, location.origin).href`。
   - `collegesOfBuilding(emblems, buildingId): College[]`：`buildingIds` 里有这个楼号的学院，按 `no` 从小到大。
   - `collegeForPlace(emblems, buildingId, texts: string[]): College | null`：先取 `collegesOfBuilding`；没有返回 `null`；只有一个返回它；有几个时，在 `texts` 里按顺序找每个学院的 `name`（去掉括号里的内容）和 `short`，出现位置最靠前的那个学院胜出（同一段里比位置，前一段出现的优先于后一段）；都没出现返回 `no` 最小的。
   - `shortName(c)`：`c.name` 去掉全角括号及里面的内容。
3. **`EmblemMark.vue`**：
   - props：`college: College`、`size: number`、`tone: 'gilt' | 'color'`、`ring?: 'none' | 'gold' | 'red'`（默认 `none`）。
   - 根元素是一个 `span`，`data-testid="stage-emblem-<no>"`、`data-tone` 是实际用的样子（`color` 但 `college.color` 为 `null` 时，实际是 `gilt`）、`role="img"`、`aria-label` 是学院全名。
   - 鎏金：宽高 `size`，圆形，`background: var(--st-gilt)`，`-webkit-mask` 和 `mask` 都写，地址用 `emblemUrl(college.mask)`，`center / contain no-repeat`。地址通过内联的 CSS 变量传进去（例如 `--mask: url("…")`），样式里写 `mask: var(--mask) center / contain no-repeat`。
   - 本色：同样大小的圆，`background: url(emblemUrl(college.color)) center / contain no-repeat`。
   - `ring`：`gold` 是 `box-shadow: 0 0 0 1px var(--st-gold2)`；`red` 是 `0 0 0 2px var(--st-red), 0 0 22px rgba(226, 0, 26, .55)`。
4. **`stores/stage.ts`**：加字段 `emblems: Emblems | null`，`StageView` 挂载时 `loadEmblems()` 放进去；取失败时保持 `null`，控制台打一条警告，**舞台照常工作**（后面的卡在 `emblems` 为 `null` 时一律不画院徽）。加字段 `collegeNo: number | null` 和动作 `showCollege(no)`：设 `collegeNo`，再对这个学院的第一栋在当前沙盘上的楼调 `showBuilding`（W9 有这个动作；没做 W9 的，调 `showAnswer`）；`goHome()`、`pickCampus()`、`switchPack()` 把 `collegeNo` 清成 `null`。
5. **自查用的排版**：网址带 `emblems=1` 时，`StageView` 左上角（顶栏下面）放一个 `data-testid="stage-emblem-sheet"` 的容器，两行各 24 枚、每枚 40 像素：第一行 `tone="gilt"`，第二行 `tone="color"`。不带这个参数时不渲染。

## 常见错误

- 蒙版地址写成相对地址：CSS 变量里的 `url()` 按样式表的位置解析，会去错的目录找，后端对找不到的文件返回 200 加首页 HTML，所以不会报 404，只是显示不出来。用 `emblemUrl()`。
- 把蒙版图用 `<img>` 显示出来：白色加透明，在黑底上是一个白色的院徽轮廓，不是金色的。
- `tone="color"` 时没有判断 `color` 为 `null`：继续教育学院和护理学院会是空的。
