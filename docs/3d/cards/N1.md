# N1 换资产包，高亮改成显示高亮件

**做完的样子**：打开 `/?3d=1`，沙盘是夜景，有轮廓线和光柱；鼠标移到板块按钮上，对应的楼变成红色并立起红色光柱。画面此时还是静止的，这是对的。

**前提**：`frontend/public/campus3d/` 里已经是 v2 的四个文件（`campus.meta.json` 里 `"version": "v2"`）。不是的话停下，等协助方的文件。

**只许改**：`src/campus3d/meta.ts`、`src/campus3d/scene.ts`、`src/components/CampusHero.vue`、`tests/unit/meta.test.ts`、`tests/unit/glb.test.ts`、新建 `tests/e2e/night.spec.ts`。

## 要做的事

1. **`meta.ts`**：给 `CampusMeta` 加上 `look` 字段，类型按 `NIGHT.md` 第 3.2 节逐项写。`parseMeta` 里校验：
   - `look.highlight.nodePrefix`、`look.fx.node`、`look.intro.clip` 是非空字符串；
   - `look.highlight.riseMs`、`look.fx.speed`、`look.fx.maxFps`、`look.intro.seconds`、`look.intro.cameraMs` 是大于 0 的有限数；
   - `look.intro.cameraFrom.position` 和 `target` 各是 3 个有限数；
   - `look.hud.title`、`subtitle`、`coord`、`scaleLabel` 是非空字符串；
   - `look.hud.scale100` 里每个停靠点（`stops` 的每个键）都有一对点，每个点是 3 个有限数；
   - `look.hud.scalePoster.desktop` 和 `mobile` 是 0 到 1 之间的数；
   - `look.colors` 的六个值都是 `#` 开头的 7 位颜色。
   不合格时抛 `Error`，信息里写明字段名。
2. **`scene.ts`，加载后**：遍历模型，把名字以 `meta.look.highlight.nodePrefix` 开头、并且**父节点是模型根节点**的对象收进一张「楼号 → 对象」的表（楼号是名字去掉前缀）。应该正好 5 个。**不要改它们的缩放、不要动 `visible`。**
3. **`scene.ts`，`setHighlight(board)`**：
   - 删掉原来克隆材质、改颜色的代码，连同释放克隆材质的代码。
   - 新做法：找到这个板块的热点的 `buildingId`，把表里对应对象的缩放设成 `(1, 1, 1)`；把上一个高亮的对象的缩放设回 `(0, 0, 0)`。传 `null` 时只做后一半。
   - 改完请求渲染一帧（和原来一样）。
4. **如果以前做过 S10b（高亮的楼抬起）**：楼抬起多少，对应的 `H_` 对象的 `position.y` 也设成多少；落回时一起落回。没做过 S10b 就跳过这一条。
5. **调试钩子**新增三个字段：
   - `assetVersion`：`meta.version`；
   - `hotNodes`：第 2 步那张表里有几个对象，未加载时为 0；
   - `hotVisible`：当前缩放不为 0 的那个对象的楼号，没有则为 `null`。
   `highlightMaterials` 保留，以后恒为 0。

## 验证

- `version === 'v2'`，`parseMeta` 不抛错。
- 三个反例都抛错：删掉 `look`；把 `look.fx.speed` 改成字符串；删掉 `look.hud.scale100.overview`。

`tests/unit/glb.test.ts` 增加（从 GLB 的 JSON 块里读）：
- 每个热点都有名为 `H_<buildingId>` 的节点；它没有 `mesh`，有 `children`，`scale` 等于 `[0, 0, 0]`。
- 有名为 `meta.look.fx.node` 的节点，并且带 `mesh`。
- `animations` 里恰好一个片段，名字等于 `meta.look.intro.clip`。

`tests/e2e/night.spec.ts`（全部用 `/?3d=1` 打开，截图前隐藏 `campus-overlay`）：
1. `ready` 后：`assetVersion === 'v2'`，`hotNodes === 5`，`hotVisible === null`。
2. 对画布截图统计：饱和红色（R > 170、G < 70、B < 70）占比小于 0.0005；暗色（R + G + B < 150）占比大于 0.5；暖色亮像素（R > 180、G > 110、B < 170、R − B > 40）占比大于 0.001。
3. 鼠标移到「教务」按钮，等 `moving === false`：`hotVisible` 等于 meta 里「教务」热点的 `buildingId`；饱和红色占比大于 0.003；`highlightMaterials === 0`。
4. 鼠标移到页面空白处，等 `stop === 'overview'` 且 `moving === false`：`hotVisible === null`，饱和红色占比小于 0.0005。
5. 依次悬停 5 个按钮，每个都等 `moving === false`：`hotVisible` 每次都等于各自热点的 `buildingId`。
6. 在 5 个按钮之间来回移动 20 次后：`geometries`、`textures` 和移动前相同。
7. 之前所有测试仍然全绿。
