# N2 黑色画框、四角信息条、新标记样式

**做完的样子**：沙盘是一块嵌在白色页面里的黑色画面，四角有等宽字体的信息条，五个标记带着板块名；悬停时标记变红并展开楼名，右下角显示楼名和服务数量。静态版和 3D 版看起来一样。

这张卡只有 DOM 和 CSS，不碰 three。

**只许改**：`src/components/CampusHero.vue`、`src/views/HomeView.vue`、`src/styles/swiss.css`、新建 `tests/e2e/hud.spec.ts`。

## 外观表（照这个做，不要自己发挥；颜色都取自 `meta.look.colors`）

**画框**（`campus-hero`）
- 背景色 `colors.panel`。1px 黑色边框、直角、宽高比都不变。
- 海报图铺满画框（`object-fit: cover`）。
- meta 还没加载到时，背景先用 `#05080d`，不许出现白底。

**画框里新增的装饰层**（都盖在画布上面、标记下面，`pointer-events: none`）
- 暗角：径向渐变，中心在 `50% 55%`，从 45% 处的全透明到 100% 处的 `rgba(2, 4, 8, 0.55)`。
- 扫描线：1px 白线、间隔 2px 的横向重复条纹，整层透明度 0.05。
- 四个角标：各 14×14px 的直角折线，线宽 1px，颜色 `colors.hud`，透明度 0.55，离画框边 10px。

**四角信息条**（`var(--mono)` 字体，10.5px，字距 0.12em，行高 1.7，颜色 `colors.hud`，透明度 0.78；离左右边 22px，离上边 18px、下边 16px）

| 位置 | `data-testid` | 内容 |
|---|---|---|
| 左上 | `campus-hud-title` | 第一行 `hud.title`：`/` 之前的部分加粗、不透明；第二行 `hud.subtitle` |
| 右上 | `campus-hud-coord` | 第一行 `hud.coord`；第二行「`<楼数> BUILDINGS · <热点数> BOARDS`」，楼数是 `meta.buildings` 的条数，热点数是 `meta.hotspots` 的长度 |
| 左下 | `campus-scale` 和 `campus-scale-label` | 一条比例尺（高 5px，左、右、下三边 1px 实线）加文字 `hud.scaleLabel` |
| 右下 | `campus-hud-readout` | 没有高亮时：`移到板块上查看位置`。有高亮时：`■ <编号> <楼名> · <note>`，方块是 `colors.accent` 色；拿到了服务数量时在末尾再加 ` · <N> 项服务` |

- 视口宽度 ≤ 720px 时：右上和左下不显示，字号 9px。
- 四个信息条外面包一层 `data-testid="campus-hud"`。

**比例尺的宽度**
- 静态版：画框宽度 × `hud.scalePoster.desktop`（视口 ≤ 720px 时用 `mobile`）。
- 3D 版（`status` 为 `ready`）：在 `onFrame` 回调里，取 `hud.scale100[当前 stop]` 的两个点，各自 `project()`，两个投影点之间的距离（像素）就是宽度。
- 宽度变化加 300 毫秒的 CSS 过渡。

**标记**
- 按钮本身仍是 22×22px，中心对准标记点，`data-testid` 不变。背景 `colors.markerBg`（透明度 0.85），1px 边框 `colors.markerBorder`（透明度 0.8），白色编号。
- 按钮右侧紧贴一个标签，**必须绝对定位**（`left: 100%`），不能让按钮变宽。标签高 22px，字号 11.5px，背景 `rgba(8, 12, 18, 0.72)`，三边 1px 边框 `rgba(220, 232, 248, 0.35)`（左边没有），内容是板块名（`board`）。`data-testid` 为 `campus-marker-label-01` 等。
- `is-active` 时：按钮背景和边框变成 `colors.accent`；标签展开成两行，第一行楼名（`label`，12.5px 粗体白色），第二行 `note`（11px，透明度 0.7），边框变成 `colors.accent`，背景 `rgba(8, 12, 18, 0.9)`。
- 标记原来的红底样式删掉。

**画框外面一律不动**（标题、板块按钮、页面背景仍是原来的瑞士风）。说明文字和开关按钮的位置、样式不变。

## 服务数量

- `HomeView` 挂载时调用一次现有的 `api.services()`（不带参数），按每条的 `board` 字段数出各板块有几项，传给 `CampusHero`。请求失败就传空对象，不显示数量，不报错。
- 不许改 `src/api/client.ts`。

## 验证

`tests/e2e/hud.spec.ts`。假接口 `**/api/v1/services*` 返回 4 条：`board` 为「图书馆」的 3 条、「教务」的 1 条（字段照 `client.ts` 里的 `ServiceEntry` 填）。

1. `/?3d=0`：`campus-hero` 的计算背景色是 `rgb(5, 8, 13)`；`campus-hud-title` 的文字同时包含 `hud.title` 和 `hud.subtitle`；`campus-hud-coord` 包含 `hud.coord` 和「`45 BUILDINGS · 5 BOARDS`」（这两个数从 meta 现算，不要写死）。
2. `/?3d=0`：`campus-scale` 的宽度与「画框宽度 × `scalePoster.desktop`」相差不超过 2 像素。
3. `/?3d=0`：5 个标记按钮的宽和高都在 21 到 23 像素之间；每个 `campus-marker-label-NN` 可见，文字等于对应热点的 `board`。
4. `/?3d=0`：鼠标移到「图书馆」按钮：`campus-marker-05` 有 `is-active`；`campus-marker-label-05` 的文字包含该热点的 `label` 和 `note`；`campus-hud-readout` 包含 `label` 和「3 项服务」。移开后 `campus-hud-readout` 的文字是「移到板块上查看位置」。
5. `/?3d=0`，拦截并中断 `**/api/v1/services*`：悬停「图书馆」时 `campus-hud-readout` 包含 `label`，不包含「项服务」；`pageerror` 0 次。
6. `/?3d=1`，`ready` 后：`campus-scale` 的宽度与「`projectPoint(scale100.overview[0])` 和 `projectPoint(scale100.overview[1])` 之间的距离」相差不超过 3 像素。鼠标移到「教务」按钮并等 `moving === false` 再等 500 毫秒：与 `scale100` 里该热点 `stop` 的那一对点算出的距离相差不超过 3 像素。
7. 视口 390×844，`/`：`campus-hud-coord` 和 `campus-scale` 不可见，`campus-hud-title` 可见。
8. 之前所有测试仍然全绿（尤其是 `static.spec.ts` 里标记中心对位的那一条）。

## 常见错误

- 颜色、文字写死在代码里。全部从 `meta.look` 读。
- meta 加载前画框是白的，页面闪一下白。
- 比例尺在 3D 版里只算了一次，镜头转走以后不更新。
- 装饰层挡住了鼠标，画布上的悬停失灵。装饰层要 `pointer-events: none`。
