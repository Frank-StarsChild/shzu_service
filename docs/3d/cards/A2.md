# A2 学院灯牌（必做）

**做完的样子**：在校区自己的沙盘首页（中区、北区、北苑新区、南区、东区、将军山），每个学院的主楼上方悬一枚 40 像素的鎏金院徽，外面一圈深色底和细金边，一根细金线落到楼顶。两个学院在同一栋楼的并排。全校沙盘的首页不画；在全校沙盘上选中一个校区后，只画这个校区的。鼠标移上去：院徽放大到 50 并发光，右边竖排一块小题签写学院名（有建院年份的，下面一行小字写年份）；点它：镜头飞到这栋楼、楼变红、院徽还原本色。对照 `alive-lanterns.jpg`。

**原理**：灯牌和 W3 的题签一样，是一层 HTML，跟随一个场景点：每帧用 `project()` 把楼的 `anchor` 和 `anchor` 往上 `meta.look.sign.lift` 的点换成屏幕坐标。坐标只从当前沙盘的 `meta.buildings` 取。

**只许改**：`src/stores/stage.ts`、`src/views/StageView.vue`、`src/styles/stage.css`、`src/components/stage/StageCanvas.vue`（只为调试钩子加 `lanterns` 字段）；新建 `src/components/stage/CollegeLanterns.vue`、`tests/e2e/stage-lanterns.spec.ts`；`tests/unit/stage-store.test.ts` 里追加。

## 要做的事

1. **画哪些**（写成 `CollegeLanterns.vue` 里的一个计算属性）：`stage.emblems` 为 `null` 时一个都不画。否则对当前沙盘 `meta.colleges` 的每一条：
   - 在 `emblems.colleges` 里找到同 `no` 的学院；它的 `buildingIds` 里**第一个在 `meta.buildings` 里的楼号**就是灯牌的楼。没有就不画。
   - `mode === 'home'`：当前沙盘是 `packs.json` 的 `default`（全校）时不画；校区沙盘全画。
   - `mode === 'campus'`：只画 `zone` 等于 `zoneId` 的。
   - `mode === 'answer'`、`mode === 'tour'`：不画（回答时院徽放在楼的题签顶上，见 A3）。
2. **样子**（每枚一个 `div`，`data-testid="stage-lantern-<no>"`）：
   - 外层用 `transform: translate(-50%, -100%)` 把底端对准楼 `anchor` 的屏幕点；从上到下是：一个圆（`padding: 3px`，底色 `rgba(7, 10, 15, .86)`，`box-shadow: 0 0 0 1px var(--st-gold2), 0 6px 18px rgba(0,0,0,.6)`）里面放 `EmblemMark`（40，`gilt`）；下面一根 1 像素的竖线，从 `--st-gold` 渐变到透明，长度等于「`anchor` 的屏幕 y − (`anchor` 往上 `sign.lift` 的点)的屏幕 y」，最短 12 像素。
   - **同一栋楼有几个学院**：横向错开，第 i 个（从 0 起，共 n 个）的偏移是 `(i − (n − 1) / 2) × 48` 像素。
   - 悬停（`:hover` 或键盘聚焦）：院徽 50，圆的 `box-shadow` 换成 `0 0 0 1.5px var(--st-gold), 0 0 26px 4px rgba(232, 201, 138, .55)`；右边出现竖排小题签（`writing-mode: vertical-rl`，宋体 600 12px，字距 0.24em，近黑底，1px 淡金边，顶边 1.5px 金线），文字是 `shortName(学院)`；`year` 不为 `null` 时，题签下面一行 10px 等宽小字写年份。
   - 灯牌是 `button`，`aria-label` 是学院全名。点了调 `showCollege(no)`（A1）。
3. **层级**：放在场景标签层（和 W3 的题签同一层，`z-index` 3），在面板之下。不挡 W9 的序号标记：W9 的标记在楼的 `anchor` 上，灯牌在它上方。
4. **每帧更新**：位置在 `onFrame` 回调里算（同 W7 的写法）；画面外的（屏幕坐标超出视口 40 像素以上，或在相机背后）隐藏。
5. **调试钩子**：`window.__campus3d.lanterns` 是当前可见的灯牌数。
6. 静态模式（没有 3D）下不画。

## 验证

`tests/unit/stage-store.test.ts` 追加：`showCollege(5)`（当前沙盘是 `bq`）之后 `collegeNo === 5`，`place.buildingId === 'BQ-B013'`；之后 `goHome()`：`collegeNo === null`。

`tests/e2e/stage-lanterns.spec.ts`（1440×900，`/stage?3d=1&intro=0`）：
1. 全校沙盘首页：`lanterns === 0`，页面上没有 `[data-testid^="stage-lantern-"]`。
2. 点 `stage-rail-ZQ`，等 `moving === false`：可见的灯牌数等于 `all` 元数据里 `zone === 'ZQ'` 的学院中、楼在 `meta.buildings` 里的个数（用测试自己从 JSON 算出来的数，不要写死）。
3. 点 `stage-rail-enter`，等 `pack === 'zq'` 且 `status === 'ready'`：每个灯牌底端的中心和 `projectPoint(它那栋楼的 anchor)` 横向相差不超过 3 像素（并排的那种按偏移量扣掉再比）、纵向不超过 3 像素。
4. 换到北苑新区（`stage-rail-BY` → `stage-rail-enter`）：`stage-lantern-2` 和 `stage-lantern-3` 的中心纵坐标相差不超过 1 像素，横坐标相差 48 ± 2 像素。
5. 在中区沙盘把鼠标移到 `stage-lantern-16` 上：它里面的 `stage-emblem-16` 宽 50 ± 1；出现「法学院」三个字。
6. 点 `stage-lantern-16`，等 `moving === false`：`mode === 'answer'`；`shell` 等于 `ZQ-B018`；`college === 16`；页面上没有 `[data-testid^="stage-lantern-"]`。
7. 七块沙盘都换一遍（全校选中每个校区一次；六个校区沙盘首页各一次）：控制台没有报错；校区沙盘首页的 `lanterns` 都大于 0。

## 常见错误

- 全校沙盘首页满屏院徽：第 1 步的判断漏了。
- 灯牌在镜头飞行时比楼慢半拍：位置在另一个 `requestAnimationFrame` 里算的。只在 `onFrame` 里算。
- 换到校区沙盘后灯牌全挤在中间：还在用上一块沙盘的 `meta`，或者 `meta` 还是 `null` 时就算了。`meta` 为 `null` 时什么都不画。
- 护理学院在南区沙盘上没有灯牌：对的，它的楼还没确认（`buildingIds` 是空的）。
