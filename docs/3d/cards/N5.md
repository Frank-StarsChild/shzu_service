# N5 高亮时红色从楼底涌起

**做完的样子**：悬停板块按钮时，那栋楼的红色不是一下子出现，而是在 0.26 秒里从楼底涌到楼顶，红色光柱跟着升起。

**只许改**：`src/campus3d/scene.ts`、新建 `tests/e2e/rise.spec.ts`。

## 要做的事

1. `setHighlight(board)` 显示某个 `H_` 对象时，不再直接把缩放设成 `(1, 1, 1)`，而是：
   - 先设成 `(1, 0.02, 1)`；
   - 在 `meta.look.highlight.riseMs` 毫秒里，把 **`scale.y`** 从 0.02 变到 1，用 `camera.ts` 里已有的缓动函数的后半段，或者写一个「先快后慢」的三次缓出（`1 − (1 − t)³`）放进 `camera.ts`；`x` 和 `z` 始终是 1。
   - 过程中每一帧都要渲染（N3 的循环在跑时自然满足；循环停着时要自己请求帧，到位后不再请求）。
2. 隐藏仍然是立刻设回 `(0, 0, 0)`。
3. 升到一半时换了别的板块：旧的那个立刻设回 `(0, 0, 0)`，新的从 0.02 开始。升到一半时取消高亮：立刻设回 0。
4. `reducedMotion` 为真时：直接设成 `(1, 1, 1)`，不做过渡。
5. **调试钩子**：`hotVisible` 的含义不变（缩放不为 0 的那个对象的楼号）；新增 `hotRise`，当前显示着的对象的 `scale.y`，没有显示时为 0。

## 验证

`tests/unit/camera.test.ts` 增加（如果新写了缓出函数）：在 0 和 1 处分别是 0 和 1，在 0 到 1 上取 21 个点单调不减。

`tests/e2e/rise.spec.ts`（`/?3d=1&intro=0`）：
1. 悬停「图书馆」按钮后，用 `page.waitForFunction` 等到 `hotRise > 0 && hotRise < 1` 出现过一次（说明确实有过渡）；1.5 秒后 `hotRise` 在 0.999 到 1.001 之间。
2. 鼠标移到页面空白处并等镜头回到 `overview`：`hotRise === 0`，`hotVisible === null`。
3. 每隔 80 毫秒依次悬停 5 个按钮，最后停在「学工」：1.5 秒后 `hotVisible` 等于「学工」热点的 `buildingId`，`hotRise` 在 0.999 到 1.001 之间；饱和红色像素占比大于 0.003（截图前隐藏 `campus-overlay`，并等 `moving === false`）。
4. `emulateMedia({ reducedMotion: 'reduce' })` 后打开，悬停「教务」按钮，200 毫秒内 `hotRise === 1`。
5. 之前所有测试仍然全绿。

**反向验证**：把过渡的终点临时改成 0.5，第 1 条的后半必须变红；改回。

## 常见错误

- 把 `x`、`z` 也一起从 0 变到 1，楼像气球一样胀出来。只变 `y`。
- 过渡结束后还在不停请求帧（循环停着的时候）。
- 快速换板块时旧的高亮件没有归零，同时红了两栋。
