# A3 学院列表、办理地点、题签顶上的院徽（必做）

**做完的样子**：问「信息学院在哪栋楼？」，楼变红，楼上那块红色题签的顶上多了一枚本色的信息学院院徽（外圈朱红）；面板「办理地点」一行左边是 48 像素的本色院徽，右边是学院名，下面一行小字「北区 · 绿2 楼」。回答落到的楼不是学院的楼（比如大学生活动中心），一切照旧（朱红小方块加楼名）。校区面板的学院列表每行在序号和名字之间多一枚 24 像素的鎏金院徽。对照 `alive-college.jpg`。

**只许改**：`src/stores/stage.ts`、`src/components/stage/AnswerPanel.vue`、`src/components/stage/SceneSigns.vue`、`src/components/stage/CampusPanel.vue`（做过 W9 才有）、`src/styles/stage.css`；新建 `tests/e2e/stage-college-place.spec.ts`；`tests/unit/stage-store.test.ts` 里追加。

## 要做的事

1. **哪个学院**（`stores/stage.ts` 的 `showAnswer(buildingId)` 里，进入 `answer` 状态那一支）：`emblems` 不为 `null` 时，`collegeNo = collegeForPlace(emblems, buildingId, 文字)?.no ?? null`。`文字`是最后一条回答的 `answer.blocks` 的每段 `text`，没有就是空数组。`showCollege(no)` 进来的，`collegeNo` 已经设好，不要被覆盖。其他让 `place` 变 `null` 的地方，`collegeNo` 一起清掉。
2. **办理地点**（`AnswerPanel.vue`，`stage-panel-place` 那一节）：`collegeNo` 不为 `null` 时，把「朱红小方块 + 楼名」换成：
   - 左边 `EmblemMark`（48，`color`，外面包一个 `data-testid="stage-place-emblem"` 的容器）；
   - 右边两行：上面宋体 700 18px 的 `shortName(学院)`；下面 12px 月白 66% 的「<片区名> · <楼名> 楼」（楼名去掉括号内容）。
   - 红色引线（W5）的起点仍是这一节的左边缘往下 36 像素，不用改。
3. **题签顶上**（`SceneSigns.vue`，楼的题签 `stage-sign-<楼号>`）：`collegeNo` 不为 `null` 时，在题签的文字框上面加一个圆（同 A2 灯牌的圆，但 `box-shadow` 是 `0 0 0 2px var(--st-red), 0 0 22px rgba(226, 0, 26, .55)`），里面 `EmblemMark`（44，`color`），整个圆 `data-testid="stage-sign-emblem"`；圆和文字框之间一根 8 像素的朱红竖线。题签的底端位置不变（整块往上长）。
4. **学院列表**（`CampusPanel.vue`，做过 W9 才有这一步）：每行 `stage-college-<序号>` 的序号和名字之间加一枚 `EmblemMark`（24，`gilt`）。行高不够时把行的上下内边距各加 2 像素，别的不动。
5. `emblems` 为 `null` 时，以上全部退回原样。

## 常见错误

- 题签加了院徽之后整块往下掉、挡住了楼：底端要对准原来的点，院徽加在上面。
- `showCollege` 点进来的学院，被 `showAnswer` 按文字重新算成了别的（同一栋楼两个学院时最明显）：第 1 步说的「不要被覆盖」。
