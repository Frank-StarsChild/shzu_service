# A5 智多星在想（回放版，必做）

**做完的样子**：问「学生证丢了，去哪补办？」。按下「问」的一刻，问话栏上方那一行变成「读题 — 翻查 — 核证 — 作答」，「读题」亮；星周围出现一圈慢慢转的金色小字。0.4 秒后「翻查」亮，星旁边一块竖排题签「翻查 学生证丢了，去哪补」。回答回来：面板立刻出现；同时「核证」亮，从星到出处的每个部门的楼各长出一根金线，线头一个小圈，旁边写「学生处 2 条」。半秒后「作答」亮，落到办事的楼的那根线变红，其余的淡出，镜头飞过去（W5 原来的流程）。对照 `alive-thinking.jpg`。

**原理**：后端这次不改。前端用「发出提问」和「回答回来」两个时刻，加上回答里的出处，把过程演出来；出处的发布单位查 `places.json` 的 `issuers` 得到楼号。阶段和金线放在 `stores/stage.ts` 的 `trace` 里（`ALIVE.md` 第 4.2、4.3 节），组件只读它。以后 A6 换成后端实时推的数据，组件不用改。

**只许改**：`src/stores/stage.ts`、`src/views/StageView.vue`、`src/components/stage/ZdxStar.vue`（做过 W7 才有；只为在 `trace` 不是 `idle` 时隐藏「智多星」三个字）、`src/components/stage/AskDock.vue`（只把等回答时的那一行换成 `PhaseLine`）、`src/components/stage/StageCanvas.vue`（只为调试钩子加 `phase`、`threads`）、`src/styles/stage.css`；新建 `src/stage/trace.ts`、`src/components/stage/AgentTrace.vue`、`src/components/stage/PhaseLine.vue`、`tests/unit/trace.test.ts`、`tests/e2e/stage-trace.spec.ts`。

## 要做的事

1. **`trace.ts`**：
   ```ts
   type TracePhase = 'idle' | 'read' | 'search' | 'verify' | 'answer' | 'error';
   interface TraceHit { issuer: string; label: string; buildingId: string | null; count: number }
   interface Trace { phase: TracePhase; requestId: string | null; query: string | null; hits: TraceHit[]; evidence: number; live: boolean }
   ```
   - `issuerLabel(issuer)`：有全角括号的取括号里的（「党委学生工作部（学生处）」→「学生处」）；否则去掉开头的「石河子大学」和「党委」（「石河子大学图书馆」→「图书馆」）。
   - `traceFromResponse(response, places, meta): Pick<Trace, 'hits' | 'evidence'>`：按 `response.citations` 的顺序，把相同 `issuer` 的合成一条（`count` 是条数），保持第一次出现的顺序，最多 5 条；`buildingId` 是 `places.issuers[issuer]`，但这个楼号**不在 `meta.buildings` 里时为 `null`**；`evidence` 是 `citations` 的总条数。`response.status` 不是 `answer`、`insufficient` 时返回空。
   - `queryOf(question)`：去掉首尾空白，取前 10 个字符。
2. **store**：字段 `trace: Trace`（初始 `{ phase: 'idle', requestId: null, query: null, hits: [], evidence: 0, live: false }`），动作 `setTrace(patch)`（合并）。`switchPack()` 时复位成初始值。
3. **驱动**（`StageView.vue`，监听 `chat` store 最后一条助手记录；规则同 W5 第 4 步：只对本次打开页面后新发出的请求）：
   - 变成 `pending`：`setTrace({ phase: 'read', requestId, query: null, hits: [], evidence: 0 })`。400 毫秒后，如果 `trace.requestId` 还是它、`phase` 还是 `read`：`setTrace({ phase: 'search', query: queryOf(用户的问题) })`。
   - 变成完成、`response.status === 'error'`（或请求本身失败）：`setTrace({ phase: 'error' })`，1.5 秒后复位成 `idle`。
   - 变成完成、其他状态：算 `traceFromResponse`。
     - 有至少一条 `buildingId` 不为 `null`：`setTrace({ phase: 'verify', hits, evidence })`；等 `450 + 90 × (有楼的条数 − 1)` 毫秒；`setTrace({ phase: 'answer' })`，**这时**才调 W5 的 `showAnswer(resolvePlace(...))`。
     - 一条都没有：`setTrace({ phase: 'answer', hits, evidence })`，立刻 `showAnswer(...)`。
     - 镜头停下（`moving` 变回 `false`）1.2 秒后，复位成 `idle`。
   - **回答面板不等**：面板照 W4 在回答回来时立刻出现，不受上面的等待影响。
   - 「减少动态效果」：没有 400 毫秒和 `verify` 的等待，阶段照常设置，`showAnswer` 立刻调。
   - 等待期间又发了新的一问：旧的计时器全部作废（比较 `requestId`）。
4. **`AgentTrace.vue`**（`data-testid="stage-trace"`，`data-phase` 是当前阶段；`phase` 是 `idle` 时不渲染；静态模式不渲染）。所有位置每帧在 `onFrame` 里算：
   - **一圈字**（`stage-trace-ring`，`phase` 是 `read`、`search`、`verify` 时显示）：一个 120×120 的 SVG，中心在星的屏幕位置（星跟随的那个场景点的投影，同 W7；没做 W7 的用 `meta.look.star.home` 的投影）。里面一个半径 42 的圆（金色 18% 不透明）、一个半径 52 的虚线圆（`2 5`，金色 10%）、一段沿半径 42 圆排的字（`textPath`，宋体 600 10.5px，字距 0.2em，金色）：「翻查审定资料 · 」加 `query`（`query` 为 `null` 时加「读题」）再加「 ·」。整个 SVG 每 8 秒顺时针转一圈。
   - **翻查题签**（`stage-trace-query`，`phase` 是 `search`、`verify` 时显示）：竖排题签，左上角在星的屏幕位置往右 44、往下 20；上面一个 11px 金色「翻查」，下面宋体 600 14px 白色的 `query`。
   - **金线**（每条 `buildingId` 不为 `null` 的 hit 一根，`data-testid="stage-trace-thread-<楼号>"`，`phase` 是 `verify`、`answer` 时显示）：画在最上层的 SVG 里。起点是星的屏幕位置，终点是 `project([anchor[0], anchor[1] + 4, anchor[2]])`；二次曲线，控制点 `x = (起点x + 终点x) / 2 + (起点y − 终点y) × 0.15`，`y = min(起点y, 终点y) − 两点距离 × 0.18`；描边 `--st-gold` 1.3px，圆头。终点一个半径 5 的空心圆和半径 1.8 的实心圆。**生长**：第 i 根（从 0 起）延迟 `90 × i` 毫秒，用 `stroke-dasharray` / `stroke-dashoffset` 在 360 毫秒里从起点画到终点。
   - **部门标签**（`stage-trace-tag-<i>`，i 从 1 起，按 hits 的顺序）：有楼的，放在线的终点正上方 14 像素：宋体 600 12px 金色 `label`，后面 10.5px 月白「N 条」；没有楼的，竖着排在翻查题签下面，不画线。
   - **作答**：`phase === 'answer'` 时，终点楼号等于 `place.buildingId` 的那根线加类名变成朱红 1.8px（终点的圆也变红），其余的线和标签在 300 毫秒里淡出。
5. **`PhaseLine.vue`**（`data-testid="stage-phase"`，`data-phase`）：`trace.phase` 不是 `idle` 时，替换问话栏上方 W4 那一行。四个宋体 600 12px 的词，字距 0.24em，中间用「—」连：当前阶段金色带一点光晕（`text-shadow: 0 0 10px rgba(232, 201, 138, .6)`）、之前的月白 66%、之后的月白 38%。`verify` 时后面接 12px 小字「<有几个部门> 个部门 · <evidence> 条审定资料」。`error` 时整行换成「这一轮没有答出来」。
6. **调试钩子**：`phase` 是 `trace.phase`；`threads` 是当前画出来的金线根数。

## 常见错误

- 面板等动画播完才出来：把面板的显示也挂到了 `answer` 阶段。面板不等，只有 `showAnswer` 等。
- 金线落在天上：终点用了 `anchor + sign.lift`。终点是 `anchor` 往上 4。
- 连问两次，第一次的金线在第二次里冒出来：计时器没有按 `requestId` 作废。
- 「智多星」三个字和转的那圈字叠在一起：`trace` 不是 `idle` 时隐藏星的字。
