# W9 学院和五个板块（可选）

**做完的样子**：选中一个校区，右边的面板列出这个校区的学院，沙盘上对应的楼顶着「一、二、三」的小标记；点一个学院，镜头飞到它的楼，楼变红。选中中区时，面板上方多一排五个板块（学工、教务、后勤、保卫、图书馆）；点「图书馆」，镜头飞到图书馆，面板列出这个板块的服务，点一条示例问题就直接提问。对照 `stage-campus.jpg`。

**只许改**：`src/stores/stage.ts`、`src/views/StageView.vue`、`src/components/stage/SceneSigns.vue`、`src/styles/stage.css`；新建 `src/components/stage/CampusPanel.vue`、`tests/e2e/stage-colleges.spec.ts`；`tests/unit/stage-store.test.ts` 里追加。

## 要做的事

1. **`stores/stage.ts`** 新增一个动作 `showBuilding(buildingId)`：效果和 `showAnswer(buildingId)` 相同（进入 `answer` 状态、镜头飞过去、楼变红或立图钉），只是不关联任何回答。再新增一个字段 `board: string | null`（当前选中的板块）；`goHome()`、`pickCampus()`、`switchPack()`、`showAnswer()` 都把它清成 `null`。
2. **`CampusPanel.vue`**（`stage-campus-panel`，包角面板，位置同回答面板）：`mode === 'campus'` 时显示。
   - 标题是校区名，右上「N 栋楼 · M 个学院」。
   - **学院列表**：当前包 `meta.colleges` 里 `zone` 等于选中片区的。每行（`stage-college-<序号>`，从 1 起）：`cnNumber(序号)`、学院名（去掉括号里的内容）、右边小字是第一栋楼的名字。`confirmed` 为假的，名字后面加小字「（位置待确认）」。点一行：先把 `board` 清成 `null`，再 `showBuilding(buildingIds[0])`。
   - 这个片区没有学院时写一行「这个校区没有学院，主要是宿舍和生活设施。」
   - **五个板块**：只在选中片区是 `places.boards` 里那些楼所在的片区（现在是中区）时显示，放在学院列表上面。一排五个题签样式的小钮（`stage-board-<板块名>`）。点一个：`board` 设成它，`showBuilding(places.boards[板块名])`。
3. **`AnswerPanel.vue` 不用改**。`mode === 'answer'` 而且 `board` 不为空时，在 `StageView.vue` 里改为显示一个板块面板（可以写在 `CampusPanel.vue` 里，用同一个组件的另一种形态，`data-testid="stage-board-panel"`）：
   - 标题是板块名；「办理地点」一节同 W5（朱红小方块加楼名）。
   - 「这个板块能办的事」：调现有的 `api.services(板块名)`，每条服务一行：`name` 和 `summary`。加载中、加载失败各有一行字。
   - 每条服务下面列出它的 `sample_questions`（最多两条），点了调 `chat` store 的 `send()`。发出去之后 `board` 清空，面板自然换成回答面板。
4. **`SceneSigns.vue`**：W3 在校区沙盘首页画的地标小题签（`stage-landmark-<no>`）改成可以点：点了 `showBuilding(热点的 buildingId)`。另外，`mode === 'campus'` 时，给这个片区每个学院的第一栋楼画一个序号标记（`stage-mark-<序号>`）：20×20 的小方块，近黑底、月白 1px 边、宋体 700 11px 的中文序号；右边一个小标签写学院的简称（去掉「学院」前面太长的部分的办法：直接用完整名字去掉括号内容）。位置是 `project(楼的 anchor)`。两个学院在同一栋楼时只画第一个。点标记等于点列表里那一行。
5. 从 `answer` 状态（由 `showBuilding` 进入的）点左侧同一个校区，回到 `campus` 状态和学院列表。

## 常见错误

- 学院对应的楼写死在代码里。全部来自 `meta.colleges`。
- 板块对应的楼用了 `hotspots`。`all` 里的 `hotspots` 是五个校区，不是五个板块；板块的楼在 `places.boards`。
- 「位置待确认」的学院也说成确定的。`confirmed` 为假的必须标出来，这是事实，不能省。
- 点了板块之后又点学院，面板还是板块面板：`showBuilding` 没走到的分支里忘了清 `board`。从学院行进入时要先把 `board` 清成 `null`。
