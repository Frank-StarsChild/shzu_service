# W5 回答落到楼上

**做完的样子**：问「学生证丢了去哪补办」，回答回来的同时，镜头飞到大学生活动中心，这栋楼从底部涌起红色、立起红色光柱，楼上方展开一块竖排的题签；面板最上面多了「办理地点」一行，一根红线从这一行连到楼上。对照 `stage-answer.jpg`、`all/focus-ZQ-B023.jpg`、`stage-pin.jpg`。

**原理**：不让大模型猜地点。回答的文字里出现的楼名、出处的发布单位，查 `places.json` 这张表得到楼号；查不到就不动镜头。规则在 `STAGE.md` 第 5.5 节。

**只许改**：`src/campus3d/scene.ts`、`src/stores/stage.ts`、`src/views/StageView.vue`、`src/components/stage/StageCanvas.vue`、`src/components/stage/SceneSigns.vue`、`src/components/stage/AnswerPanel.vue`、`src/styles/stage.css`；新建 `src/stage/places.ts`；新建 `tests/unit/places.test.ts`、`tests/e2e/stage-place.spec.ts`；`tests/unit/stage-store.test.ts` 里追加。

## 要做的事

1. **`places.ts`**：`resolvePlace(response: ChatResponse, places: Places): string | null`，纯函数，严格按第 5.5 节的四条规则。「出现位置」用 `text.indexOf(name)`。`names` 里有的名字对到的是 `null`（位置还没确认的学院）：一段文字里选中的正好是这样的名字时，这一段当作没有楼名，接着看下一段。
2. **`scene.ts`**：
   - `setShell(buildingId)`：和 `setZone` 一样的做法，对象换成 `H_` 组。楼号不在表里时什么都不显示（不抛错）。如果做过 N5（红色从楼底涌起），沿用那里的过渡。
   - `setPin(buildingId)`：取 `meta.buildings[buildingId].anchor`，把图钉组的 `position` 设成 `(anchor[0], 0, anchor[2])`，缩放设成 `(1, 1, 1)`；传 `null` 时缩放设回 `(0, 0, 0)`。
   - `goTo` 传机位对象时可以多带一个名字：`goTo(pose, { name: 'focus:ZQ-B023' })`，调试钩子的 `stop` 记这个名字。
   - 调试钩子新增 `shell`、`pin`（楼号或 `null`）。
3. **`stores/stage.ts`**，`showAnswer(buildingId)`（`meta` 是 W3 存进 store 的当前包元数据）：
   - `buildingId` 是 `null`，或者 `meta` 还是 `null`（正在换沙盘）：`place = null`，`otherPack = null`；如果 `mode` 原来是 `answer`，改成 `home`，否则不动。
   - `meta.buildings` 里有这个楼号（这栋楼就在当前沙盘上）：`mode = 'answer'`，`zoneId = null`，`place = { buildingId, name }`，`otherPack = null`。`name` 取 `meta.buildings[buildingId].name`。
   - 没有：`otherPack = { packId: places.packOf[buildingId], buildingId }`，`place = null`，`mode` 的处理同第一条。`packOf` 里也没有这个楼号时按第一条处理。
   - **判断「在不在当前沙盘上」只看 `meta.buildings`，不要拿 `packOf` 和 `packId` 比**：在中区自己的沙盘（`zq`）里，中区的楼 `packOf` 写的是 `all`，但它就在眼前。
   - `goHome()`、`pickCampus()`、`switchPack()` 都要把 `place`、`otherPack` 清掉。
4. **谁来调 `showAnswer`**：在 `StageView.vue` 里监听 `chat` store 最后一条助手记录。它变成完成状态（有 `response`）时，调 `showAnswer(resolvePlace(response, places))`；开始新的一问（最后一条助手记录变成 `pending`）时调 `showAnswer(null)`。从别的页面回到舞台、`restore()` 恢复出的旧记录**不触发**（只对本次页面打开之后新发出的请求做）。
5. **`StageCanvas.vue`** 监听 store：`mode === 'answer'` 时，
   - `setZone(null)`；
   - 楼号在 `meta.shells` 里：`setShell(楼号)`、`setPin(null)`；不在：`setShell(null)`、`setPin(楼号)`；
   - `goTo(meta.focus[楼号], { name: 'focus:' + 楼号 })`。
   离开 `answer` 状态时 `setShell(null)`、`setPin(null)`。
6. **`SceneSigns.vue`**：`mode === 'answer'` 时不显示校区题签，显示一块楼的题签（`stage-sign-<楼号>`，选中样式）：文字是 `place.name`（去掉括号里的内容）。标记点是楼的 `anchor` 再往上 `meta.look.sign.lift`，线长 60px。
7. **`AnswerPanel.vue`**：
   - `place` 不为空时，在「回答」之前多一节（`stage-panel-place`）：小标题「办理地点」，下面一个朱红小方块加 `place.name`，再下面一行小字是这栋楼所在片区的名字。
   - `otherPack` 不为空时，同样位置显示一个钮（`stage-other-pack`）：「这栋楼在「将军山校区」沙盘上，点这里换过去」（引号里是 `packs.json` 里那个包的 `name`）。点了：`switchPack(otherPack.packId)`，等新场景 `ready` 后再 `showAnswer(那栋楼)`。
8. **红色引线**（`stage-leader`，画在第 4.1 节的连线层里）：`place` 不为空且 3D 模式时，一条 1.2px、颜色 `--st-red` 的折线，三个点：`stage-panel-place` 左边缘往下 36px 处 → 往左 70px → 楼的 `anchor` 往下 6 的那个点投影到屏幕的位置再往右 30px。折线末端一个 8×8 的朱红小方块。每帧重算。面板滚动后「办理地点」出了面板的可见范围时隐藏。

## 常见错误

- 图钉立在沙盘中间或者飘在半空：见 `STAGE.md` 第 12 节第 3、4 条。
- 楼变红了但镜头没动：`meta.focus` 的键是楼号，不是停靠点名字，要把那个对象本身传给 `goTo`。
- 上一问的楼还红着：新的一问开始时没有调 `showAnswer(null)`。
- 在校区自己的沙盘里提问，楼明明在眼前，面板却给了一个「换过去」的钮：用 `packOf` 判断了在不在当前沙盘。见第 3 步最后一条。
- 一打开页面镜头就飞走了：把 `restore()` 恢复出来的旧回答也当成了新回答。
- 引线的终点漂在别处：`getBoundingClientRect()` 给的是视口坐标，连线层必须是 `position: fixed; inset: 0`，并且 `svg` 没有设 `viewBox`。
